# DataNet WC Public Earn Loop First Work Pack Hold v1

Marker: `VOID_DATANET_WC_PUBLIC_EARN_LOOP_FIRST_WORK_PACK_HOLD_V1`

## Summary

This brick restores the first public Work Credits starter work pack for the DataNet public earn loop.

The pack is for DataNet artifact verification. It gives future reviewers a public-safe starter task shape without opening submissions, awarding WC, writing a ledger, or transferring VOID.

## Work Credits policy

Work Credits are unlimited and uncapped accounting units for useful verifiable work.

This brick does not define a fixed lifetime Work Credits ceiling. It also does not issue Work Credits.

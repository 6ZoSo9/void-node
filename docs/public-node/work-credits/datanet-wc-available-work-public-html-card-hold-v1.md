# DataNet WC Available Work Public HTML Card Hold v1

Marker: `VOID_DATANET_WC_AVAILABLE_WORK_PUBLIC_HTML_CARD_HOLD_V1`

## What changed

This brick publishes a browser-visible static HTML card for the held DataNet Work Credits available-work lane:

- `/public-node/work-credits/datanet-wc-available-work-public-html-card-hold-v1.html`

It also publishes JSON metadata:

- `/public-node/work-credits/datanet-wc-available-work-public-html-card-hold-v1.json`

The card is indexed from:

- `/public-node/work-credits/index.json`

## Boundary

This is HTML-card-only and read-only.

It does not enable public submission.

It does not issue WC.

It does not append a WC ledger line.

It does not allocate or transfer VOID.

It does not access a wallet or signer.

It does not enable a runtime mutation route or mutation handler.

Work Credits remain unlimited and uncapped.

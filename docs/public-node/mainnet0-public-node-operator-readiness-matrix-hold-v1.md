# Mainnet-0 Public Node Operator Readiness Matrix Hold v1

Marker: `VOID_MAINNET0_PUBLIC_NODE_OPERATOR_READINESS_MATRIX_HOLD_V1_GREEN`

## Purpose

This document defines a public, read-only readiness matrix for prospective VOID Mainnet-0 public node operators.

The goal is to help a real operator understand what they should prepare before public node participation opens further.

This is not node registration.  
This is not validator admission.  
This is not staking.  
This is not wallet connection.  
This is not public mutation authority.  
This is not Mainnet-0 validator activation.

## Public status

Status: `readiness_hold`

Meaning: operator preparation guidance is visible, but no public action path is enabled.

## Operator-facing summary

Prospective operators can use this matrix to prepare hardware, operating system hygiene, network reachability, storage expectations, uptime expectations, and basic security posture.

Validator candidacy remains separate from public node operation. A person being ready to run a public node does not mean they are admitted as an active validator.

## Safety rule

This brick may publish readiness information only. It must not create or expose a live registration form, wallet flow, staking flow, validator activation path, node admission handler, peer mutation handler, ledger write path, or validator-set write path.

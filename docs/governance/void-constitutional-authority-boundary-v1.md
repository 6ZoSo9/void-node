# VOID Constitutional Authority Boundary v1

**Marker:** `VOID_CONSTITUTIONAL_AUTHORITY_BOUNDARY_V1_PHASE0_DRAFT`

**Status:** Phase 0 doctrine/specification draft — constraint-only; no authority activated.

**Current Phase: Phase 0 — Founder/operator-rooted construction state.**

This document defines and constrains constitutional authority. It does not activate new authority, transfer authority, create validator quorum, enable public mutation, authorize execution, grant signer/wallet access, move funds, mutate ledgers, or create public write authority.

This document is constraint-only. It cannot be used as authorization for execution, signer access, wallet access, public mutation, validator activation, fund movement, ledger mutation, or constitutional action execution.

## Current Phase Declaration

VOID is currently in Phase 0.

Validator contest authority is not active yet. Validator quorum is not active yet. Public mutation authority is not active. Signer/wallet authority is not granted. Execution authority is not granted.

Phase 0 is the protected construction state. Phase 0 is not the target state.

## Core Doctrine

Authority must be legible, typed, bounded, and contestable at every layer.

Validators are not just infrastructure. Validators are protected witnesses to VOID truth.

Constitutional authority may stop the machine. It may not secretly become the machine.

Emergency authority can preserve truth, pause risk, and force review. It cannot create ordinary truth without validator-visible process.

## Break-Glass Boundary

Break-glass authority may only pause, quarantine, or challenge.

The break-glass authority is a brake, not a steering wheel.

Break-glass authority must not transfer funds, rotate authority, rewrite history, mutate ledgers, grant signer/wallet access, enable public mutation, or become routine.

## Phase 0 Contest Boundary

Phase 0 has no active validator contest quorum.

Validators, watchers, or public observers may record objections as advisory evidence only.

Phase 0 objections do not hard-block founder/operator action.

## Forbidden Powers

Constitutional authority alone must not transfer funds, mint supply, burn supply, rewrite history, erase evidence, add permanent validators, remove validators permanently, finalize disputed state, create public mutation authority, grant signer/wallet access, or mutate ledgers.

## Amendment Boundary

An amendment to this document does not itself activate any authority.

Any authority change requires a separate typed authority packet, phase-appropriate process, proof, and receipt.

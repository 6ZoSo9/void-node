## Candidate preparation

\`--prepare\` is deliberately unprivileged and may run from an exact reviewed
feature/CI checkout as well as from Precision.

It:

1. requires the accepted V3 lock;
2. requires all V3 native/runner/credential source objects to remain at their
   reviewed Git blobs;

credentials or execute the live runner.

\`INSTALL_ACCEPTED_EPOCH2_NATIVE_LIVE_COMPOSITION_V3_CREATE_ONLY\`

1. opens trusted \`/opt\`;
2. creates a fixed root-owned mode-0755 staging directory;
3. writes native, runner and policy create-only through a retained directory
   descriptor;

5. requires exactly the three accepted entries;

   \`renameat2(RENAME_NOREPLACE)\`;

directory. Once atomic publication succeeds, a later failure reports
\`publication_state=published_needs_inspection\` and does not delete the visible
protected root.

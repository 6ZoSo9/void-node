NullFeed public preview

NullFeed is the social/data app layer planned for VOID. The goal is chat, feeds, channels, receipts, and user-owned data without surrendering the storage path to outside platforms.

DataNet social storage

Posts, channel data, and app assets should move toward DataNet-backed storage with verifiable content roots and user-controlled visibility.

Work Credits powered actions

Future NullFeed actions can use Work Credits for paid chat actions, channel effects, moderation tools, and anti-spam mechanics.

Data-owned feeds

Users should be able to carry their content and identity across nodes.

VOID/DataNet backed

Feed objects should be content-addressed, mirrored, and verifiable.

Not cloud-first

NullFeed should not require Google Cloud or any other provider as canonical infrastructure.

Quick start

Clone the repo, install dependencies, start the node, then open the participant app. The goal is one clear path first, then packaged installers later.

git clone https://github.com/6ZoSo9/void-node

cd void-node && npm install && npm run build

Why run a node?

Running a node helps keep VOID independent. The website itself is now served DataNet-first by VOID nodes with repo fallback.

Verify the site

Use the manifest to verify the DataNet dataset id, content root, aliases, and that Google Cloud is not canonical infrastructure.

Download / Run a Node

VOID Network Mainnet-0 is live.

This is the first public live checkpoint for VOID Network. The network status has been promoted to public_mainnet0_live / GO_PUBLIC_MAINNET0 after explicit launch approval, live OpsTreasury seed, public-live proof updates, and cross-box verification on Precision and Alienware.

## What is live

- VOID Mainnet-0 node runtime is live.
- Public status is public_mainnet0_live / GO_PUBLIC_MAINNET0.
- Precision and Alienware are synced and cross-box proven.
- Public launch docs are available under docs/public.
- Participants can run a local node and open the participant page.
- Public validator registration is candidate/waiting only.
- Buy VOID has a guarded, operator-auditable fulfillment path.
- OpsTreasury has been seeded with 1,000,000 VOID.

## What remains guarded

- Public active validator admission remains disabled.
- Public candidate/waiting registration is not active validator admission.
- Vault126 onboarding has not been executed.
- Buy VOID fulfillment remains explicit, payment-verified, and tx-ref-recorded only.
- No blind deposits are supported.
- Exchange and custodial sends are unsupported where the participant flow warns against them.
- Future treasury spend remains separately guarded.
- No additional authority transfer is authorized by the launch status.

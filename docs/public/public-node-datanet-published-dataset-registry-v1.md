# DataNet Published Dataset Registry v1 (Mainnet-0)

<!-- MARKER: VOID_DATANET_PUBLISHED_DATASET_REGISTRY_DOC_V1 -->

This document defines the Mainnet-0 DataNet published dataset registry.

The registry lists public-safe metadata from operator-published manifests generated by:

```bash
ops/mainnet0/datanet-operator-local-publish-v1.sh
Registry behavior

The registry may expose:

dataset ID
manifest marker
source type
hash algorithm
object count
total bytes
content root SHA-256
manifest SHA-256
public safety flags

The registry must not expose:

absolute source path
operator home path
local storage root
shell commands
private keys
secrets
tokens
Safety

public_mutation=false

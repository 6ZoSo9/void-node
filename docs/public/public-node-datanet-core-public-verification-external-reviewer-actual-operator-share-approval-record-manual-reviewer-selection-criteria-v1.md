Reviewer selection criteria:

- Reviewer should be independent from the operator.
- Reviewer should be able to read public proof material.
- Reviewer should not require private credentials, private commands, tokens, secrets, or operator machine access.
- Reviewer should be able to verify public claims from public artifacts.
- Reviewer should be willing to report disagreement or uncertainty.
- Reviewer result must not create automatic approval.
- Operator must still manually accept or reject any future reviewer result.

Selection boundary:

- Criteria are recorded.
- No reviewer is selected.
- No reviewer is contacted.
- No packet is shared.
- No external review is started.
- No reviewer result is accepted.
- No approval record is created.
- No authority is added.

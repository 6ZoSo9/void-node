# VOID self-hosted public seed note

Status: historical design note retained for public-seed architecture context.

VOID should not default to buying or renting external infrastructure for public seed/bootstrap capacity.

Public seed capacity should be built into the network itself using existing operator machines, safe self-hosted exposure, and future participant-run seed nodes.

At the time of this note, Precision was the builder/prover and Alienware was the first internal public-seed candidate.

Current topology note (2026-09-30): Alienware is permanently retired. The active operator fleet is Precision, Nimo, and Xiphos, and the configured public HTTPS seed origin is `https://seed.nullfeed.org`. Fresh qualification and an unexpired bootstrap manifest remain separate authority requirements.

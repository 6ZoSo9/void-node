# Public Release Checklist

## Content
- [ ] Claims match current runtime truth
- [ ] No investment, guaranteed-return, or automatic-yield language
- [ ] Buy VOID language matches fulfillment authority
- [ ] Validator language separates candidate, waiting, and active
- [ ] Work Credits remain reviewed accounting units

## Security
- [ ] Exact GET proxy allowlist reviewed
- [ ] POST, PUT, PATCH, and DELETE rejected
- [ ] No operator, signer, secret, wallet-export, or private RPC route
- [ ] CSP and anti-framing headers present
- [ ] Public-sensitive-route proof green

## Accessibility
- [ ] Keyboard navigation works
- [ ] Skip link works
- [ ] Focus indicators are visible
- [ ] Mobile menu exposes expanded state
- [ ] Live status uses polite announcements
- [ ] Reduced motion is respected

## Deployment
- [ ] Remove noindex only for intentional launch
- [ ] Change robots.txt only for intentional launch
- [ ] Confirm canonical/social URLs
- [ ] Run content validator
- [ ] Verify public routes externally

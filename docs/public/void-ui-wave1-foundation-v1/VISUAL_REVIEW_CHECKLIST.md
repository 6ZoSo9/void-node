# VOID Wave 1 Visual Review Checklist

## Global shell

- [ ] Looks like one coherent product rather than a collection of tools
- [ ] Header is useful without dominating the page
- [ ] Seven primary destinations are understandable
- [ ] Current destination is unmistakable
- [ ] Account and network context are visible but compact
- [ ] Advanced feels separate from normal participant work

## Density and hierarchy

- [ ] One dominant task per page
- [ ] Supporting information does not compete with the task
- [ ] No “card for every number” effect
- [ ] Typography hierarchy is clear
- [ ] Spacing feels deliberate and consistent
- [ ] Copy is concise

## Visual language

- [ ] Graphite/cyan/violet feels like VOID
- [ ] Neon effects are restrained
- [ ] Semantic status colors are clear
- [ ] Identifiers use monospace without making the whole product look like a terminal
- [ ] Surfaces feel related across pages

## Responsive

- [ ] Desktop shell works at 1440×900
- [ ] Desktop shell works at 1280×800
- [ ] Tablet layout works at 768×1024
- [ ] Mobile layout works at 390×844
- [ ] Minimum width works at 320×568
- [ ] Mobile More sheet is understandable
- [ ] Bottom navigation does not obscure content

## Accessibility

- [ ] Keyboard route navigation works
- [ ] Focus is always visible
- [ ] Escape closes overlays
- [ ] Overlay focus returns to its trigger
- [ ] Current route is announced
- [ ] Reduced-motion preference is respected
- [ ] Status is not conveyed by color alone

- [ ] Approved for Wave 2 typed adapters
- [ ] Approved with listed changes

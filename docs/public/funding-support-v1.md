# VOID Network funding and support

VOID Network is now publicly reachable through a safe public seed adapter.

Current public seed:

- https://zoso-alienware-aurora-r7.taila47fd.ts.net

What is live now:

- public-safe seed adapter
- participant page
- readiness endpoint
- public bootstrap endpoint
- seed adapter health/status endpoint
- DataNet/public docs surfaces
- private RPC remains blocked
- sensitive wallet/admin/operator surfaces remain blocked

What VOID is building:

VOID is a decentralized data and coordination network for AI agents, participants, and useful work.

The current focus is simple and practical:

- keep the public node online
- let people reach the participant page
- let people verify public state
- make DataNet useful for storing and serving data
- turn useful verifiable work into Work Credits
- grow toward a real participant-run network

Why funding helps:

Funding helps pay for:

- hardware
- internet uptime
- domain/DNS/tunnel infrastructure
- public docs
- UI polish
- testing
- security hardening
- first user onboarding
- development time

How to help:

- test the public participant page
- share feedback
- run a node when public instructions are ready
- sponsor development
- contribute code/docs
- help test DataNet storage and public readback
- help find bugs in public surfaces

Current safety posture:

- VOID is experimental
- public validator admission is not open as automatic active admission
- Buy VOID fulfillment is not automatic
- Work Credits and token flows are guarded
- no investment return is promised
- do not send funds expecting automatic token delivery
- private JSON-RPC is not public
- wallet files, keys, secrets, admin routes, and operator routes are blocked

Public proof routes:

- /__void/adapter.json
- /__void/ready.json
- /__void/public-bootstrap.json
- /__void/public-seed-adapter/status.json
- /participant

Support message:

VOID needs funding, testers, builders, and early believers. The project is live enough to inspect, but still early enough that help can meaningfully shape it.

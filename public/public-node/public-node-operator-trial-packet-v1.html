VOID Public Node Operator Trial Packet v1

Status: trial packet ready

Marker: VOID_PUBLIC_NODE_OPERATOR_TRIAL_PACKET_V1

Expected proof marker: VOID_PUBLIC_NODE_OPERATOR_TRIAL_PACKET_V1_GREEN

This is a public-safe operator/tester packet for walking the VOID public node operator path and returning evidence for manual review.

Boundary

  • Read-only public routes only.
  • No wallet sends.
  • No money movement.
  • No Buy VOID fulfillment.
  • No WC issuance.
  • No WC→VOID swap.
  • No validator admission or mutation.
  • Tester receipts are not network truth.
  • Operator review is required.

Operator path

  1. Read the public operator quickstart
  2. Open the connect pack
  3. Use the receipt template
  4. Compare against the receipt example
  5. Package the handoff evidence
  6. Review against the checklist
  7. Record a review decision

Evidence requested

  • tester handle or operator alias
  • UTC timestamp
  • public node route tested
  • local environment summary safe to disclose
  • commands run, excluding secrets and private paths
  • observed result
  • errors or mismatch notes
  • receipt template filled with public-safe evidence only

Do not submit

  • wallet private keys or mnemonics
  • env files
  • node keys
  • API tokens or RPC credentials
  • private IPs unless intentionally disclosed by the tester
  • funds transfer claims
  • validator admission claims
  • claims that tester receipts are network truth

What this is

This page maps the major VOID lanes so reviewers and contributors can quickly see what exists, what is held, and what is explicitly not live.

This is not a ledger, wallet, validator registry, transaction route, execution gate, or authority surface.

Lane map

DataNet

Phase: public discovery and verification surface.

Static discovery, reviewer, closeout, final-seal, and browser-visible status artifacts exist.

Not live: public upload, object write, mirror command, peer-pin command, runtime mutation route.

Work Credits

Phase: public earn-loop status and operator review.

Work Credits are unlimited/uncapped accounting units for useful verifiable work.

Not live: public issuance, public claim, public ledger append, automatic reward, wallet-triggered settlement.

Mainnet-0 Validators

Phase: candidate visibility and readiness hold.

Validator surfaces are candidate/readiness/reviewer visibility only.

Not live: public registration, active admission, stake lock, validator-set write, epoch activation.

USDC/VOID Buy Pool

Phase: public status and reviewer visibility.

Buy-only public status and reviewer surfaces exist. Automatic fulfillment remains disabled.

Not live: automatic fulfillment, buyer execution route, wallet fulfillment, USDC transfer, VOID transfer.

Apollyon

Phase: advisory identity and safety boundary.

Advisory AI identity only; no autonomous authority.

Not live: autonomous commits, ledger writes, wallet access, validator changes, secret access.

Public Node

Phase: static reviewer gateway.

The public node is a static/read-only reviewer and discovery gateway across VOID lanes.

Not live: public mutation handlers, runtime writes, wallet connections, signing, fund transfer execution.

Boundary

The Build Map does not create authority. It only points at existing public-safe surfaces and summarizes hold state.

no wallet connect no signer access no ledger write no WC issuance no VOID transfer no validator admission no runtime mutation no autonomous AI write

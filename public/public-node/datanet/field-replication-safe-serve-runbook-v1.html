DataNet field replication safe serve runbook v1

Status: repeatable operator runbook.

This public-safe runbook repeats the source-node to field-node DataNet replication loop using npm run public-node:serve, not a generic Python HTTP server.

Required commands

  • Source serve: npm run public-node:serve -- --port 8088
  • Field mirror serve: npm run public-node:serve -- --port 8089
  • Field runner: npm run datanet:field-replication:run
  • Source verifier: npm run datanet:field-object:roundtrip
  • Field report: npm run void:field-report

Expected markers

  • VOID_PUBLIC_NODE_SAFE_SERVE_V1_READY
  • VOID_DATANET_FIELD_REPLICATION_RUNNER_V1_GREEN
  • VOID_DATANET_FIELD_OBJECT_ROUNDTRIP_V1_GREEN
  • VOID_FIELD_REPORT_V1_READY
  • dangerous_paths_touched=false
  • match=true

Boundaries

This runbook is read-only and does not enable wallet movement, WC settlement, validator admission, public mutation routes, ledger writes, automatic rewards, or secret handling.

Private tailnet addresses and hostnames are intentionally redacted from public status.

Tester flow

  1. Read the tester instruction pack.
  2. Copy the tester receipt template.
  3. Use the tester receipt example as a formatting reference only.
  4. Record public-safe observed results.
  5. Submit only for operator review.

Boundary

  • Read-only public rollup only.
  • No submission endpoint is enabled here.
  • No wallet send, money movement, WC issuance, WC ledger write, validator admission, validator mutation, or runtime truth is enabled.
  • Tester receipts are not network truth.
  • Real receipts require operator review.

DataNet WC Agent Attestation Envelope Schema Candidate

This public-safe schema candidate defines the shape of an agent attestation envelope for DataNet Work Credits review lanes.

Envelope includes

  • Actor identity envelope reference.
  • Submitted work artifact reference.
  • Evidence packet reference.
  • Proof command reference.
  • Reviewer or operator decision reference.
  • Work Credit award status.
  • Authority boundary fields.

Boundary

  • Schema candidate only.
  • No identity registry write.
  • No attestation registry write.
  • No public mutation route.
  • No automatic Work Credit issuance.
  • No Work Credit ledger write.
  • No reviewer staking activation.
  • No VOID transfer.
  • No wallet path.

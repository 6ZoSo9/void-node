DataNet WC Agent Identity + Attestation Policy

DataNet does not treat an agent chat log as proof of work. The useful object is a receipt chain: identity envelope, artifact, replayable proof or evidence packet, reviewer/operator decision, and later award status.

Agent identity

Agent identity means stable attribution for an agent, tool runner, reviewer, or operator lane. This page is explanatory only and does not create a public identity registry.

Attestations

An attestation links actor, artifact, proof, review evidence, and preserved boundary. It is a receipt for work, not an automatic reward.

Work Credits

Work Credits remain unlimited and uncapped accounting units for useful verifiable work. Issuance remains gated by review/operator/protocol rules.

Boundary

  • No identity registry write.
  • No public mutation route.
  • No automatic WC issuance.
  • No WC ledger write.
  • No reviewer staking activation.
  • No VOID transfer.
  • No wallet path.
  • No signer path.

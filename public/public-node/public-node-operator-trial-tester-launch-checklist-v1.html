This checklist helps outside testers run the public node operator trial and submit a clean, public-safe, non-authoritative tester receipt for operator review.

Before testing

  • Open the tester kit public entrypoint link.
  • Read the tester instruction pack.
  • Confirm you are not using private keys, wallet secrets, API keys, passwords, or private personal data.
  • Choose a public-safe tester alias and unique run ID.

During testing

  • Record public routes checked.
  • Record public-safe commands run.
  • Record observed results and warnings.

After testing

  • Copy the tester receipt template.
  • Use the tester receipt example as formatting reference only.
  • Submit only for operator review.

Boundary

  • Read-only public checklist only.
  • No submission endpoint is enabled here.
  • No wallet send, money movement, WC issuance, WC ledger write, validator admission, validator mutation, or runtime truth is enabled.
  • Tester receipts are not network truth.

This is a public-safe manual intake guide for outside testers or operators submitting a real trial receipt for operator review.

Submission policy

  • Manual operator review required: true
  • Operator-provided submission channel required: true
  • Public upload route enabled: false
  • Public form enabled: false
  • Submitted receipts are not network truth.
  • Submission does not authorize WC, ledger writes, wallet sends, money movement, or validator admission.

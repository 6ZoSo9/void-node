VOID Public Node Operator Trial Tester Receipt Template v1

Marker: VOID_PUBLIC_NODE_OPERATOR_TRIAL_TESTER_RECEIPT_TEMPLATE_V1

Expected proof marker: VOID_PUBLIC_NODE_OPERATOR_TRIAL_TESTER_RECEIPT_TEMPLATE_V1_GREEN

This is a copy-safe public tester receipt template for recording observed public node operator trial results before operator review.

Boundary

  • Read-only public template only.
  • No submission endpoint is enabled here.
  • No wallet send, money movement, WC issuance, WC ledger write, validator admission, validator mutation, or runtime truth is enabled.
  • A tester receipt is not network truth.
  • Real receipts require operator review.

Required receipt fields

  • tester_alias
  • run_id
  • timestamp_utc
  • node_version_or_commit
  • environment_os
  • network_mode
  • public_routes_checked
  • commands_run
  • observed_results
  • failures_or_warnings
  • tester_attestation
  • requested_review_action
